# Software and Interactive Tools

This page contains software and interactive tools useful for studying Materials
Science and Engineering.

## Atomic and crystal structures

Tools for drawing, visualizing, and exploring atomic and crystal structures
will be added during the course.

## Phase diagrams

Tools for constructing and interpreting phase diagrams will be added during
the course.

## Materials properties

Tools and databases for exploring materials properties will be added during
the course.

## Suggest a tool

Students are welcome to suggest relevant software and interactive tools through
the [dedicated submission page](https://github.com/sten8/MSE-booklet/issues/new?template=content-suggestion.md).
